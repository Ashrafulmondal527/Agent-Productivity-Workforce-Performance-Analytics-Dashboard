# Agent-Productivity-Workforce-Performance-Analytics-Dashboard
Agent Productivity Dashboard is an interactive MS Excel dashboard designed to analyse and monitor agent productivity, quality, schedule adherence, shrinkage, and process distribution. The dashboard transforms operational data into actionable business insights through slicers, KPI cards, performance charts, target comparisons & agent-level rankings.
# Business Objective 

## The objective of this project is to create a centralized reporting solution that enables management to: 

Monitor overall agent productivity. 

Track Average Handle Time (AHT). 

Evaluate Quality performance. 

Monitor Schedule Adherence. 

Analyse Shrinkage. 

Understand employee/process distribution. 

Compare Team Leader performance. 

Identify top-performing Team Leader. 

Compare actual performance against predefined targets. 

Support data-driven workforce management decisions.
